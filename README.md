# 오늘 지갑운
React 18, TypeScript, Vite로 만든 앱인토스 브라우저용 MVP.

## 실행 및 검증
Node.js 24에서 아래 명령을 사용한다.
```sh
npm ci
npm test
npm run build
npm run dev
```
기본 주소는 http://localhost:5173 이다. 새 브라우저 프로필에서 입력 → 결과 → 보너스 열기를 확인한다. 광고는 3초 모의 재생이며, 주소에 `?ad=no-fill` 또는 `?ad=fail`을 붙이면 로드 실패와 재생 실패를 각각 확인할 수 있다.

## 다른 AI에 전달할 검토 요청
[공개용 기획서](docs/plan.md)의 2장 S1~S3와 4장을 기준으로 구현을 검토해 줘. 날짜 경계·윤달·출생 시간, 점수 계산, 광고 중도 이탈·당일 재노출, 브라우저 뒤로가기와 새로고침을 확인해 줘. 결함마다 파일과 줄 번호, 재현 절차, 기대값과 실제값을 적어 줘. 브라우저에서 확인한 항목과 토스 실기기가 필요한 항목을 구분해 줘.

## 검토 시 적용한 기준
- 음력 1900~2100년의 한국 단기력 월 시작일과 월 길이를 번들에 포함한다. 표 재생성은 Node.js 24에서 `node scripts/generate-lunar-table.mjs`로 실행한다. 생년월일에는 미래 날짜를 허용하지 않는다.
- 입력 단위가 두 시간이라 절기는 해당 구간의 대표 시각으로 판정한다. 자시는 입력 날짜 00:30 KST, 모름은 12:30 KST다. 년주·월주 계산에만 UTC+8 시각을 쓰고 일주는 입력한 한국 날짜를 쓴다. 실제 절기 시각을 포함하는 구간에서는 정확한 출생 분에 따라 결과가 다를 수 있다.
- 점수 순위는 같은 프로필의 60갑자 점수에서 오늘 점수 이하가 차지하는 비율이다. 광고는 프로필을 수정해도 하루 한 번만 지급하고, 처음 열었던 프로필로 돌아오면 보너스를 다시 표시한다.
