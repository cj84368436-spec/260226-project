# 토스 앱에서 보상형 광고 확인하기

## 1. 콘솔 등록 정보 확인

앱인토스 콘솔에서 테스트할 워크스페이스와 비게임 미니앱을 선택한다. 앱 ID가 `apps-in-toss.config.ts`의 `appName`인 `today-wallet-fortune`과 정확히 일치해야 한다. 콘솔에 다른 ID로 등록했다면 빌드 전에 설정을 맞춘다. 콘솔 앱 정보에서 한글 브랜드명 **오늘 지갑운**, 앱 아이콘, 소개와 스크린샷을 확인한다. 아이콘과 표시 이름은 SDK 3.x 콘솔에서 관리한다.

## 2. 테스트 ID로 번들 만들기

Node.js 24에서 프로젝트 루트의 다음 명령을 실행한다.

```sh
npm ci
npm test
npm run build
```

QR 테스트 시에는 `VITE_TOSS_AD_GROUP_ID`를 비워 두거나 `ait-ad-test-rewarded-id`로 지정한다. 셸과 로컬 환경 파일 양쪽을 확인한다. 빌드는 TypeScript 검사 → Vite CSR 번들 → `ait build` 순서이며, 기본 산출물은 프로젝트 루트의 `today-wallet-fortune.ait`다.

## 3. 브라우저에서 예외 경로 확인

`npm run dev`로 실행한 뒤 새 브라우저 프로필을 이용한다. S2에서 잠금 버튼을 눌러 S3으로 이동한다. 일반 브라우저에서는 3초 모의 광고를 쓰며, 재생 중 **광고 닫기**를 누르면 S3에서 다시 시청할 수 있다. `/?ad=no-fill`은 준비 실패, `/?ad=fail`은 재생 실패를 재현한다. 각 경로에서 무료로 3개가 열리는지 확인한다.

현재 SDK 3.x의 로컬 개발 환경은 브라우저다. 전용 샌드박스 앱은 2.x용이며, 실제 인앱 광고 확인에는 아래의 콘솔 QR을 사용한다. [샌드박스 지원 버전](https://developers-apps-in-toss.toss.im/development/test/sandbox) · [보상형 광고 SDK](https://developers-apps-in-toss.toss.im/documentation/common/monetization/iaa/interstitial-rewarded-ad)

## 4. 콘솔 QR로 iOS·Android 테스트

1. 콘솔의 대상 미니앱에서 **출시하기**로 이동해 테스트 ID로 만든 `.ait`를 업로드한다. 업로드한 버전의 QR 코드를 열고, 테스트 권한이 있는 계정으로 로그인한 최신 토스 앱에서 실행한다. 재빌드한 경우 해당 버전의 QR을 사용한다. [토스 앱 테스트 가이드](https://developers-apps-in-toss.toss.im/guide/operation/toss)
2. 그날 보너스를 열지 않은 프로필로 무료 결과를 확인한다. S2 진입만으로 광고가 재생되면 안 된다. S3에서 로드 완료 후 재생 버튼이 활성화되는지, 버튼을 눌렀을 때 **네이티브 테스트 광고**가 표시되는지 확인한다. ‘모의 광고 3초’가 보이면 SDK 지원 여부와 토스 버전을 확인한다.
3. 먼저 보상 획득 전에 네이티브 광고를 닫는다. S3에 중단 안내가 남고, 새 광고가 준비된 뒤 다시 재생할 수 있어야 한다. 다음 시청에서는 보상 획득까지 진행한다. S2에 번호·지출·부스터가 모두 표시되고, 광고를 닫은 뒤에도 유지되는지 확인한다.
4. 같은 날 앱을 닫았다 다시 열어 같은 프로필에 보너스가 유지되는지 확인한다. iOS와 Android 각각에서 화면 상·하단 잘림, 뒤로가기, 광고 종료 후 터치와 스크롤 복귀도 확인한다.

## 5. 출시용 광고 그룹 적용

콘솔에서 이 앱의 **보상형** 광고 그룹 ID를 복사하고 프로젝트 루트의 `.env.production.local`에 다음 값을 설정한다.

```dotenv
VITE_TOSS_AD_GROUP_ID=콘솔에서_발급받은_보상형_광고_그룹_ID
```

셸에 남은 같은 이름의 테스트 환경변수가 있으면 해제한다. `npm run build`를 다시 실행해 생성한 출시용 번들을 콘솔에 올린다. Vite가 빌드 시 값을 포함하므로 이전 테스트 번들과 업로드 대상을 구분한다. 출시 요청 전에 콘솔 등록 정보, 광고 그룹과 보상 명칭, QR 테스트 결과를 확인한다.
